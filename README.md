# Memory Card Game

A memory game built with React as part of [The Odin Project](https://www.theodinproject.com/).

## How to Play

- Click on a card to earn a point.
- Don't click on the same card twice!
- Cards are shuffled after every selection.
- Your current score resets when you select a previously clicked card.
- Try to beat your best score!

## Features

- Dynamic card rendering using data fetched from an external API.
- Randomised card order after each selection.
- Current score and best score tracking.
- React hooks for state management and data fetching.

## Technologies

- React
- JavaScript
- CSS
- External API
